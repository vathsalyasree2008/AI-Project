# 🤖 AI Full Stack Project

This project is a collection of AI applications developed using **Python, Ollama, and Streamlit**.

The project focuses on learning how to build AI-powered applications, interact with local Large Language Models (LLMs), and create simple web interfaces for AI chatbots.

---

## 🚀 Features

- 🤖 AI chatbot using a local LLM
- 🧠 Integration with Ollama
- 💬 Interactive chatbot interface
- 🌐 Streamlit-based web application
- 💾 Chat history using Streamlit session state
- 🐍 Built using Python
- ⚡ Runs AI models locally

---

## 🛠️ Technologies Used

- **Python**
- **Ollama**
- **Llama 3.2:3b**
- **Streamlit**
- **Git & GitHub**
